# 火山方舟 LLM 插件

FlowCloudAI WASM 插件，用于适配火山方舟豆包模型的 Chat Completions API。

## 支持模型

- `doubao-seed-2-1-pro-260628`
- `doubao-seed-2-1-turbo-260628`
- `doubao-seed-2-0-lite-260428`
- `doubao-seed-2-0-mini-260428`
- `doubao-seed-2-0-code-preview-260215`

## 构建

```bash
cargo fcplug build
```
